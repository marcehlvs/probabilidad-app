pm# Probabilidad desde cero (5.º año)

App interactiva en React + Vite, con la misma base visual que `estadistica-app`.

Solapas: Laplace y sucesos · Simulador · Combinatoria (guía, teoría de cada tipo y práctica completa o solo de reconocimiento) · Probabilidad condicional · Diagramas de árbol · Ejercicios por nivel (4 niveles, con ejemplos resueltos y explicados y práctica) · Modo evaluación · Hoja de fórmulas · Mi progreso · Armar grupos.

```bash
npm install
npm run dev      # desarrollo
npm test         # verifica los generadores de ejercicios
npm run deploy   # publica en GitHub Pages (rama gh-pages)
```

El progreso se guarda solo en el navegador (localStorage).
