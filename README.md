# Probabilidad desde cero (5.º año)

App interactiva en React + Vite, con la misma base visual que `estadistica-app`.

Solapas: Laplace y sucesos · Simulador · Combinatoria · Probabilidad condicional · Diagramas de árbol · Modo evaluación · Hoja de fórmulas · Mi progreso · Armar grupos.

```bash
npm install
npm run dev      # desarrollo
npm test         # verifica los generadores de ejercicios
npm run deploy   # publica en GitHub Pages (rama gh-pages)
```

El progreso se guarda solo en el navegador (localStorage).
